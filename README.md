# Reinforcement Learning for High School Timetabling

## Overview

This project investigates the application of
Reinforcement Learning to the High School
Timetabling Problem.

The scheduling process is modeled as a
Markov Decision Process (MDP).

A Maskable PPO agent is used to generate
valid timetables while respecting hard
constraints through Invalid Action Masking.

---

## Features

- Reinforcement Learning Scheduler
- Maskable PPO
- Invalid Action Masking
- Multi-input Observation Space
- Timetable Evaluation
